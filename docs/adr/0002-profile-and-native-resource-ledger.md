# 按执行配置路由，保留原生资源账本

2026-09-05 审阅 Q9 已确认本决定。同名模型经订阅、官方 API 和第三方通道运行时，认证、费用和工具能力不同，因此以版本化 Execution Profile 为目标，每 Attempt 固定绑定；换源创建新 Attempt，通过平台交接包继续工作。

配额保留共享关系和原生单位，本地预留与服务消费分别核对。相比统一 token 余额，这增加配置/账本复杂度，但避免重复分配账户额度、隐藏现金路径和虚假精确余量。详见 [路由与配额](../architecture/02-routing-and-quota.md)。
