## 4. 已确认工程基线包

以下在 Q9 获用户整体确认，ADR 0002/0003 已转为 accepted，文档状态为“设计基线已确定、待 M0 验证”。

- 技术：Python/FastAPI＋React/TypeScript＋SQLite，模块化后端与独立执行/交付进程；不预建分布式基础设施。
- 执行：版本化 Profile 和原生资源账本；独立副本、冻结候选、独立验证、唯一交付入口到 PR。
- 完成定义：必需本地检查与独立 Review 通过并确认 PR 创建即完成；远端 CI 单列，项目可事先设为额外完成条件；不自动合并。
- 可调初值：每项目 2 writer、每 Run 2 轮质量修复、每根任务最多 2 次基础设施重试；所有消费和重试仍受总预算/次数/时间上限限制。
- 实施顺序：M0 先用假 provider 和一个订阅端＋一个 API 端验收接口，再扩展完整链路与全部选定来源。
- 恢复：历史备份不能当正常重启自动继续；核对后由用户针对恢复状态决定继续，正常重启按原有效授权自动恢复。

确认这个包不填写真实金额、不启用 Profile，也不授权本轮调用服务或开始编写平台实现。
