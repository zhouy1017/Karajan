# M4-02｜备份恢复、升级与保留

Parent：[PRD v1 #1](https://github.com/zhouy1017/Karajan/issues/1)

## 目标

一致备份、历史恢复、升级与受管清理可用。

## 本轮执行边界

用户已授权完整设计、拆票、实现和 GitHub gate；**本轮不执行任何现金 API 调用，真实 API 验收保持 not_run**。禁止订阅/额度错误后转额外余额或现金后备。开发、安装本地依赖、假 provider、协议回放、真实本机进程/文件测试和不产生现金模型请求的 GitHub 工作可在已授权范围内继续；缺具体账户、模型、金额、仓库或能力事实时，只阻塞依赖它的真实路径。

本票的 Blocked by 是最终验收/能力启用 gate，不禁止独立离线工作。离线实现可以完成并单独验收其实际覆盖行为；真实资格或完整端到端条件未满足时保持未勾选/not_run，不据此宣称该能力或阶段全通过。已有配置授权不重复询问，空值不解释成无限权限或预算。

## Scope

一致数据库/产物/操作记录备份，正常安装升级与资格失效，历史恢复的 epoch/冻结/核对/用户继续决定，磁盘不足/缺产物和保留清理。提供实际可用的本地维护入口与运行说明。

提供实际本地数据库/产物/操作记录、版本 manifest、受管备份目录、磁盘不足/缺文件注入和迁移样例；秘密独立管理，不复制进普通备份导出。

## 接口与输入契约

下列契约未冻结时先按现有设计与假实现开展工作；最终集成绑定精确版本和能力证据。仅记录 Fxx 编号、字段名或支持布尔值不足以启用能力。

- F01（来自 M0-01）：冻结版本化 Execution Profile、Attempt Manifest、事件/资格报告字段与稳定 reason code；不能由未认识的字段推导权限。
- F02（来自 M0-02）：冻结持久启动身份/start_key、启动许可 activation、inspect/cancel 及 running/exited/unknown 的事实边界；未知启动不能重新 spawn。
- F03（来自 M0-03）：冻结原币预算、父子调用切片、receipt 与可选 logical ID、send intent/send_unknown 和结算协议；无法证明未发送的占用不能释放。
- F04（来自 M0-04/05/06）：冻结各 adapter 实际接受的模型/原生设置、单次权限答复和工具/进程/网络隔离声明，包含不可用或未覆盖路径。
- F05（来自 M0-07 及后续来源资格）：冻结精确版本/环境下真实合格的 Profile、允许角色/能力和执行接口；离线 fixture 不让 Profile 自动获得 enabled 或 bounded_calls。

## 验收标准

- [ ] 备份后产生执行/消费/撤销/远端变化，再恢复旧快照：旧 activation/outbox 不执行，缺历史保留 unknown，不恢复已撤销权或把旧余额变新钱。
- [ ] 用户针对当前核对结果选择继续。
- [ ] 缺证据/磁盘满不交付；删除只限真实解析后的受管路径且无活进程。
- [ ] 真实备份恢复、数据库迁移和假秘密导出检查均留证。
- [ ] 验收记录逐项标明真实或 fake 的覆盖；本轮现金 API 实际请求数为零，相关真实验收保持 not_run，未执行项不勾选。
- [ ] 提交实现 commit/PR、可运行入口、固定输入与执行命令、实际结果/副作用证据及限制；失败与重跑历史保留，不能只提交文档或 fixture 宣称通过。

## 离线与真实验证的边界

**本轮可做：**实际创建和恢复数据库/产物/操作记录备份，用可控 provider/remote 事实模拟备份后消费/撤销；真实测试缺文件、磁盘不足、迁移和受管路径清理。

**不足与真实 gate：**只检查备份文件存在或 mock restore 不足；必须真正恢复并观察冻结/核对/用户决定。假外部事实不证明真实服务账单或 GitHub 状态，相关远端变体由真实 gate 补齐，现金 API 分支本轮 not_run。

**必须保存：**保存版本/内容 manifest、恢复 epoch、旧 activation/outbox 拒绝、历史 unknown/撤销、继续决定、缺证据阻断及假秘密未导出。

证据应绑定实现 commit、case/variant、Profile/runtime revision（如适用）、OS/隔离、日期和结果；只保存 secret_ref 与脱敏身份，不把实际凭据、原始认证材料或秘密写入 Issue/日志/导出。能力结果区分 passed、failed、not_run、unsupported，后两者不计为通过。
