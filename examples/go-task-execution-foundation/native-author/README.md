# Native Task producer author evidence

The new trusted producer receives immutable approved-workspace bytes and mandatory controller start/send callbacks. It returns a real StoppedProjection and a content-free observation; Candidate validation, approval, current fencing, and acceptance remain controller responsibilities.

The 22-case Linux final run passed using the pinned OpenCode ELF and offline tokenizer with synthetic local HTTP. It includes an actual read/edit changing subtraction to addition, measured Journal send intents committed before HTTP, immutable stopped bytes, and withdrawal of the per-send guard after the first response with no second upstream send. Controller business guards in these producer tests are explicit substitutes, not real Run admission evidence. Windows passed 7 platform-independent cases with 15 Linux skips. Ruff and mypy for Linux and Windows passed.

The first expanded run had 6 passes and 16 failures caused solely by a missing test `dataclasses.replace` import (removed by Ruff before later tests used it). The product source was unchanged; correcting the test import yielded 17 affected input cases passing, followed by all 22 passing. Original XML remains in the worktree cache. No real provider or user credential was used.
