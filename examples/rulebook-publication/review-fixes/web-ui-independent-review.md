# 发布 HTTP 与工作台的独立实现审查

审查范围为本批新增 `web/projects.py` 发布入口、对应 HTTP 测试，以及 `RulebookPanel`、样式、交互测试和 `App` 接线。审查者没有编写这些模块；ProjectRegistry 持久层由本审查者实现，其独立审查另有记录。

确认的 1 个 P2 已闭合：发布响应未知后，从项目工作台切到资源页再回来，原实现丢失未决命令和编辑。`ui-unresolved-navigation.case.tsx`、原输入与 before 保持原字节；修复后使用同一公开 App 用例得到 `ui-unresolved-navigation.after.json`，1 passed。恢复记录保存于同一标签页的会话存储，发送前验证记录完整保存；恢复只提供显式原请求重试，旧组件迟到响应不能删除新实例记录。

独立实际执行结果分别为：

- 作者的 HTTP 测试：10 passed。覆盖会话、CSRF、Origin、版本与命令身份，实际预览/发布/重试/重启历史和不写容量账。
- 审查者追加真实 TestClient 检查：9 项通过。包括四入口匿名访问、重复版本/命令头、发布额外字段、跨项目预览和拒绝后没有发布副作用。
- 作者的 UI 交互测试：42 passed。含 409 保留编辑并重新预览，未知结果保持完整请求，切换资源/配置/需求/其他项目后的同请求重试，加载/文件读取/响应正文的代际检查，以及固定字段保护和三项协作上限编辑。
- 审查者原始导航反例：1 passed，记录独立于作者测试。

没有未闭合的确凿问题。未把父任务实际浏览器操作计作本审查者执行的测试；其编辑→预览→发布→刷新→历史记录和运行/容量/启用状态对照见上级 `browser-verification.json`。

已明确的恢复限制：同一标签页、同一登录会话可恢复原请求；退出后新登录可查看发布历史，不恢复旧会话重试身份。页面有相应说明，退出登录保持可用。

源码范围、原证据摘要和实际测试计数绑定在 `web-ui-independent-review-index.json`。原用例可由仓库 Python 环境运行 `ui_navigation_replay.py <新的输出文件名.json>` 重放，不覆盖已有报告，也不改产品源码。
